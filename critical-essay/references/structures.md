# 结构库：先判断争点，再挑结构

## 一、判断争点

争点理论（stasis theory）源自古希腊的赫尔玛戈拉斯，西塞罗、昆体良等罗马修辞学家做过完善。它的用处是找出分歧到底卡在哪一层。层次判断错了，后面怎么写都是答非所问。

| 争点 | 要回答的问题 | 题目里常见的样子 | 主张的样子 |
|---|---|---|---|
| 事实 | 这件事是否存在、是否发生 | “……是否导致了……”“……真的在下降吗” | X 存在 / X 发生了 |
| 定义 | 它算什么、该归到哪一类 | “……算不算……”“如何理解……” | X 属于 Y / X 应理解为 Y |
| 因果 | 为什么会这样、会带来什么 | “……的成因”“……会造成什么影响” | X 主要由 Y 引起 |
| 价值 | 好不好、对不对、哪个更重要 | “……是否合理”“评价……”“A 与 B 孰优” | X 是好的 / X 比 Y 更可取 |
| 对策 | 应该怎么做 | “是否应当……”“如何应对……” | 应当做 X |

判断时注意两件事：

1. **对策以前面几层为前提。**主张“应当禁止 X”，至少要先站稳“X 有害”（因果）和“这种害大于它的好处”（价值）。前提层如果有争议，就要写；没有争议，用一两句交代清楚后跳过。
2. **主争点只有一个。**课程论文篇幅有限，一个主争点加一两个前置争点就够了。几层都想争，最后哪层都争不透。

## 二、匹配表

先看主争点，再看读者（任课老师、同学、文中设定的对话对象）对立场的态度，从表里挑 2–3 个候选。

| 主争点 | 读者态度 | 首选 | 备选 |
|---|---|---|---|
| 事实 / 定义 | 中立 | 古典六部式 | 图尔敏全篇式 |
| 事实 / 定义 | 已有流行说法、需要推翻 | 驳立结合式 | 古典六部式（反驳前置） |
| 因果 | 中立 | 图尔敏全篇式 | 古典六部式 |
| 价值（单一对象好不好） | 中立 | 图尔敏全篇式 | 古典六部式 |
| 价值（两难、各有道理） | 分裂 | 正反合辩证式 | 罗杰斯式 |
| 价值（比较 A 与 B） | 任意 | 比较评估式 | 正反合辩证式 |
| 价值 / 伦理 | 多数持反方 | 罗杰斯式 | 正反合辩证式 |
| 对策 | 前置争点有争议 | 争点递进式 | 图尔敏全篇式 |
| 对策 | 前置争点无争议 | 图尔敏全篇式 | 比较评估式（比较几个方案） |
| 评论某学者 / 教材 / 观点 | 任意 | 驳立结合式 | 正反合辩证式 |

表只是起点。题目原文带了结构暗示（“试评述”“请比较”“谈谈你的看法”）、或者老师在要求里点了名，就按那个来。

**混用规则**：全文选一个宏观结构。不管选哪个，每个分论点内部都写成图尔敏单元（见 `toulmin-unit.md`），复述对方时都用 Rapoport 规则（见 `critical-tests.md` 第三节）。

## 三、七种结构

每种结构给出：怎么组织、适合什么、代价、章节骨架、常见错误。骨架里的“部分”不等于一级标题，篇幅短时可以几部分合成一节。

### 1. 古典六部式

源自西塞罗等人的演说结构：引言、陈述、划分、确证、驳斥、结语。先立后驳，立场一开头就亮明。

- **适合**：立场明确，材料充分，读者中立，争的是事实或定义。
- **代价**：对立面要到后半段才出场，读者本来就持反方的话，会觉得前面都在自说自话。

骨架：
1. 引言：引出争议，亮出中心主张。
2. 背景陈述：交代议题的来龙去脉、关键概念的界定。只摆事实，不急着论证。
3. 论点预告：本文从哪几方面论证。一两句即可。
4. 立论：分论点逐个展开，强的放最前或最后。
5. 驳论：最有力的一到两个反方观点，逐个回应。
6. 结语：回到限定后的主张，交代论证的边界。

变体：流行说法和本文立场相反时，把驳论提到立论前面，先清场再立论。

常见错误：驳论只挑最弱的反方来打；背景陈述写成了教材综述，占掉三分之一篇幅。

### 2. 图尔敏全篇式

全文就是一个放大的图尔敏论证：中心主张由几条理由支撑，每条理由都有依据和保证，最后用限定条件和反驳收束。重在推理链清楚。

- **适合**：因果、价值、对策题；老师看重推理是否严密。
- **代价**：读起来像推理链，叙事性弱；如果每条保证都展开，会显得啰嗦。

骨架：
1. 引言：争议是什么，中心主张（带限定）。
2. 概念与背景：界定关键词，交代讨论范围。
3. 理由一：依据，保证（读者可能不认同时才展开，需要时加支援）。
4. 理由二、理由三：同上。
5. 反方与回应：集中处理；也可以拆开，放到对应理由的后面。
6. 结论：重申限定后的主张，说明哪些条件变了，结论就要跟着变。

反方放哪里：反方针对的是某一条理由，就紧跟那条理由；反方针对的是整个主张，就集中放在最后。

常见错误：把“理由”和“依据”写成一回事，只堆材料，不说材料怎么推出主张；限定条件只在结论里出现一次，正文里的主张却说得很绝对。

### 3. 罗杰斯式

修辞学家 Young、Becker、Pike 根据心理学家卡尔·罗杰斯的沟通理论提出的写法。先把对方的立场讲公道，再讲自己的立场，最后找双方都能接受的方案。目标是让持反方的读者愿意往前挪一步。

- **适合**：伦理、价值冲突大的议题；读者多数持反方；题目要求“回应某种担忧”。
- **代价**：立场亮得晚，篇幅花在对方身上，容易被看成不够锋利；不适合事实之争，事实问题没法靠妥协解决。

骨架：
1. 引言：陈述问题本身，说明分歧的双方是谁。此处可以只说本文要寻求什么样的结论，主张留到第 4 部分正式提出。
2. 对方立场：按对方会认可的方式复述，包括它最强的理由。
3. 对方立场的合理范围：在哪些情境下它是对的。
4. 本文立场：清楚提出主张和理由。
5. 本文立场的合理范围：在哪些情境下它更好，为什么这些情境是本议题的主要情境。
6. 共同基础与方案：双方都在乎的价值；本文方案怎样照顾到对方的关切。

学术论文里用这个结构，第 4 部分的主张必须和古典式一样明确，否则就成了调解报告。

常见错误：第 2 部分写成反话或捧杀；第 6 部分写成“双方各退一步”，没有具体方案。

### 4. 正反合辩证式

正题和反题都有讲得通的理由时，先把两边都推到最强，再诊断它们分歧的根源，最后提出一个新的主张，这个主张能解释两边各自对在哪里，又比两边都更站得住。对一个问题有多个可选答案时，单纯的立论加反驳不够用，需要这种正—反—合的综合论证。

- **适合**：两难问题；题目本身就呈现对立（“有人认为……也有人认为……”）；“如何看待”类开放题。
- **代价**：最容易滑成和稀泥。合题必须是一个新的、可以被反驳的主张，“两者都有道理，应当结合”不算合题。

骨架：
1. 引言：摆出对立，说明为什么简单站一边不够。
2. 正题：主张及其最强的理由和证据。
3. 反题：同等篇幅，同等力度。
4. 分歧诊断：两边在哪个前提、哪个概念、哪个适用条件上分道扬镳。这是全文最关键的一节。
5. 合题：新的主张。常见的三种做法：
   - 条件化：在条件 A 下正题成立，在条件 B 下反题成立，并论证本议题处在哪种条件下；
   - 重新界定：双方用的是同一个词的不同义项，换一个更准确的概念后，分歧消失或转移；
   - 上升一层：双方共享的某个前提有问题，换掉这个前提，得到第三种主张。
6. 合题的代价与边界：合题放弃了什么，面对什么反驳。

常见错误：反题写得比正题弱，显得是在给结论铺路；第 4 节缺失，从正反直接跳到“所以要辩证看待”。

### 5. 争点递进式

按“事实 → 定义 → 价值 → 对策”一层层往上推，每层回答一个问题，前一层的结论是后一层的前提。中文写作里说的“层进式”“是什么—为什么—怎么办”，放到学术论文里大致就是这个结构。

- **适合**：问题—对策型论文；社会现象评论；政策分析。
- **代价**：篇幅长；前几层没有争议的话，会显得在凑字。

骨架：
1. 引言：提出最终要回答的对策问题，说明它依赖哪几个前置问题。
2. 事实层：问题是否存在，规模如何。
3. 定义 / 因果层：它是什么性质的问题，主要由什么引起。
4. 价值层：它有多严重，值不值得付出代价去解决，和其他价值冲突时怎么取舍。
5. 对策层：应当做什么；为什么是这个方案而不是另外两个；方案的副作用。
6. 结论：串起各层的结论，指出哪一层最不稳固。

没有争议的层，用一两句话交代“学界对此并无分歧”并给出依据，然后往上走。

常见错误：对策层只有一句“应当加强……”；对策和前面诊断出的原因对不上。

### 6. 驳立结合式

以一个具体的观点为靶子：先准确复述，再拆开它的论证，指出问题，最后提出替代主张。只驳不立，文章会空。驳完之后一定要立。

- **适合**：评论某位学者、某本教材、某个流行说法；读书报告里的批判部分。
- **代价**：成败取决于靶子立得准不准，必须有原文可引；靶子太弱，整篇论文的分量跟着变轻。

骨架：
1. 引言：靶子是什么，谁持有，为什么值得回应。
2. 复述：引原文，按对方会认可的方式重建它的论证，把隐含的保证也写出来。
3. 拆解：标出它用的论证型式，按 `critical-tests.md` 第一节找出答不上的关键问题。
4. 驳斥：选一种或几种方式：
   - 攻击依据：事实不对，或材料不足以支撑；
   - 攻击保证：从依据推不出主张；
   - 提出反例或例外：主张在某类情况下明显不成立。
5. 立论：替代主张，以及它的理由。替代主张要能解释对方观点为什么看起来有道理。
6. 回应：替代主张面对的主要反驳。

常见错误：驳斥落在对方的动机、身份上（诉诸人身）；替代主张只是把对方的话反过来说。

### 7. 比较评估式

比较两个或几个对象（理论、政策、方案、作品）谁更好。核心是先把评价标准定下来并为它辩护，再按标准逐条比较。

- **适合**：“A 与 B 孰优”“评价几种方案”“比较两种理论的解释力”。
- **代价**：标准选哪些、谁轻谁重，本身就会被质疑，标准的论证要占不小的篇幅。

骨架：
1. 引言：比较什么，为什么要比，结论是什么。
2. 评价标准：选哪几条，为什么，权重如何。标准要能从议题的目的里推出来，不是随手列的。
3. 逐条比较：按标准组织段落，不按对象组织。按对象组织会写成两篇介绍文拼在一起。
4. 综合判断：在这些标准和权重下，谁更好，好在哪里。
5. 稳健性检验：换一种合理的权重，结论会不会翻转；会翻转的话，说明在什么条件下翻转。
6. 结论。

常见错误：标准是事后为结论量身挑的；所有标准都打成平手，最后“各有千秋”。

## 四、推荐消息怎么写

在第 3 步给用户的消息里，每个候选写成这样（可以用 AskUserQuestion，选项的 description 里放骨架预览）：

```markdown
**本题的争点**：主争点是对策（是否应当……），前置争点是因果（……是否真的导致……），这一层目前有争议，需要论证。

**候选结构**

A. 争点递进式（推荐）
怎么组织：先证明 X 确实造成了 Y，再评估 Y 有多严重，最后论证应当采取 Z。
为什么适合：前置的因果争点有争议，必须先站稳。
代价：篇幅偏长，因果层要用掉三分之一左右。
骨架：引言 → X 与 Y 的因果关系 → Y 的严重程度与代价 → 方案 Z 及替代方案比较 → 结论

B. 正反合辩证式
……

C. 图尔敏全篇式
……
```

推荐项放第一个，推荐理由要来自第 2 步的分析，不要写“更全面”“更有深度”这类空话。
