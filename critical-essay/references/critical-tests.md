# 检验工具：论证经不经得起问

## 一、论证型式与关键问题

Douglas Walton 把日常论证归纳成几十种“论证型式”，每种都配一组关键问题。这些论证不是演绎上必然成立的，而是推定成立：只要有人提出一个关键问题而你答不上来，论证就被削弱，举证责任回到你这边。

用法：第 4 步给每个分论点标出型式，把对应的问题逐个答一遍。答不上来的，三选一：补证据；收窄主张；把它写进反方回应。

下面是课程论文里最常用的十种。问题是按 Walton 的思路改写的中文版本，不是逐字翻译。

### 1. 诉诸专家意见
形式：E 是领域 D 的专家，E 认为 A，所以 A 可信。
- E 真的是专家吗？凭什么这样说？
- E 的专长是 D 吗？还是在跨领域发言？
- E 原话到底说了什么？有没有被断章取义？
- E 有没有利益相关、立场偏向？
- 其他专家同意吗？有没有反对意见？
- E 的判断有没有证据支撑，还是只是个人看法？

### 2. 因果论证
形式：A 和 B 相关（或 A 先于 B 发生），所以 A 导致 B。
- 相关是真实的吗？样本够大、够有代表性吗？
- 是不是巧合？
- 有没有第三个因素同时导致了 A 和 B？
- 方向会不会反过来，是 B 导致了 A？
- 有没有说得通的作用机制？

### 3. 诉诸后果
形式：做 A 会带来好（坏）的后果 C，所以应当（不应当）做 A。
- C 真的会发生吗？有多大可能？依据是什么？
- C 有多严重（多重要）？
- 做 A 还会带来什么别的后果，有没有抵消 C 的？
- 不做 A，C 是不是也会发生？

### 4. 实践推理（目的—手段）
形式：目标是 G，做 A 能实现 G，所以应当做 A。对策题几乎都是这个型式。
- G 真的是值得追求的目标吗？和其他目标冲突时怎么排序？
- 除了 A，还有没有别的手段能实现 G？A 是其中最好的吗？
- A 真的做得到吗？成本是多少？
- A 有什么副作用？

### 5. 类比论证
形式：情况 X 和情况 Y 相似，X 中 P 成立，所以 Y 中 P 也成立。
- X 和 Y 在与 P 有关的方面真的相似吗？
- 两者有没有关键差异，恰好会影响 P？
- 有没有另一个同样相似、但结论相反的类比？

### 6. 从例子到一般
形式：这些例子都有性质 P，所以这一类都有性质 P。
- 例子够多吗？有没有挑选过？
- 例子有代表性吗？
- 有没有反例？

### 7. 征兆论证
形式：观察到迹象 S，S 通常意味着 A，所以 A 很可能成立。
- S 和 A 的联系有多可靠？
- S 还可能意味着什么别的东西？

### 8. 定义归类
形式：X 具有特征 F，具有 F 的属于类 C，所以 X 属于 C。定义争点的核心型式。
- X 真的具有 F 吗？
- 这个定义是公认的，还是为了得出结论临时下的？
- 有没有属于 C 却不具有 F 的边界情况，说明定义太窄或太宽？

### 9. 诉诸先例
形式：过去在类似情况中做了 A，所以这次也应当做 A。
- 先例和当前情况真的类似吗？
- 先例本身做得对吗？
- 情况有没有变化，使先例不再适用？

### 10. 诉诸多数 / 常识
形式：大多数人认为 A，所以 A 可信。
- 这个“大多数”有依据吗，还是想当然？
- 在这个问题上，多数人的看法和真假有关吗？（事实问题通常无关，部分规范问题有关）
- 有没有理由认为多数人在这里有系统性偏差？

## 二、写作前的自问（Paul-Elder 框架）

Richard Paul 和 Linda Elder 把思考拆成几个要素，再用一组思维标准去检验。动笔前用要素自问一遍，写完用标准检查一遍。

**要素自问**：
- 目的：这篇论文要让读者接受什么、做什么？
- 问题：要回答的问题，能不能用一句话、带问号写出来？
- 信息：用哪些证据？哪些证据对我不利？
- 推论：从证据得出的结论，有没有跳步？
- 概念：关键概念我是怎么用的？前后一致吗？
- 假设：我默认了哪些东西是真的？读者也默认吗？
- 含义：如果我的主张成立，会推出什么？那些推论我也接受吗？
- 视角：我站在谁的角度？换一个角度看，问题会变成什么样？

**思维标准**（检查时逐条问）：清晰（读者能不能复述我的主张）、准确（事实对不对）、精确（够不够具体）、相关（这段和主张有关系吗）、深度（有没有碰到问题真正难的地方）、广度（有没有考虑其他视角）、逻辑（前后自洽吗）、重要性（抓的是主要问题还是枝节）、公正（对对方公平吗）。

## 三、复述对方：Rapoport 规则

丹尼特在《直觉泵和其他思考工具》（Intuition Pumps and Other Tools for Thinking，2013）里转述了博弈论学者 Anatol Rapoport 的批评规则，原本用于评论他人观点。用在论文里：

1. 先把对方的立场复述得清楚、生动、公平，让对方读了会说“我自己都没说得这么好”。
2. 列出你同意对方的地方，尤其是不那么显而易见的。
3. 说出你从对方那里学到了什么。
4. 做完前三步，才开始批评。

论文里不一定每一步都写出来，但第 1 步一定要做到。检验方法：把复述的那段单独拿出来，持这个立场的人读了会不会点头。

## 四、论证自检清单（第 6 步）

**整体**
- [ ] 中心主张能用一句话说出来，而且能被反驳。
- [ ] 主张带了限定，说清在什么范围、什么条件下成立。
- [ ] 争点判断对了：没有在对策题里只写事实，也没有在事实题里大谈应当。
- [ ] 结构和用户选定的一致。
- [ ] 引言交代了分歧是什么、本文立场是什么、全文怎么走。
- [ ] 结论没有超出正文论证过的范围。

**主次**（AI 写作最容易丢的一项，逐条认真过）
- [ ] 篇幅最多的是中心主张的理由，不是某个限定、反方或旁支推论。
- [ ] 引言第一段先亮主张，没有先亮限定或前提。
- [ ] 每个次要点（限定、让步、旁支推论）只在一处展开，没有在对比表、规划、结论里反复出现。
- [ ] 限定保持限定的分量：没有写成“先……才能……”的前提，也没有写成“真正关乎成败的是……”（见 `toulmin-unit.md` 第五节末尾）。
- [ ] 把限定那一节整段删掉，读者仍能说出中心主张和主要理由。

**分论点**
- [ ] 每个分论点都有主张、理由、依据，依据和主张之间有解释。
- [ ] 读者可能不认同的保证，已经明说并给了支援。
- [ ] 每个论证型式的关键问题都过了一遍，答不上的已经处理。
- [ ] 分论点之间不重复，也不互相矛盾。

**反方**
- [ ] 最强的反方观点出现了，篇幅足够。
- [ ] 复述对方的段落，持该立场的人会认可。
- [ ] 回应落在对方的理由上，没有落在对方的动机或身份上。
- [ ] 至少有一处承认对方有道理，并把它吸收为限定或让步。

**证据**
- [ ] 每条外部依据都来自用户材料，或已核实真实存在。
- [ ] 引用的意思和原文一致，没有断章取义。
- [ ] 自己推出来的结论写成推论（“由此可以推出”），没有写成材料、图表或原文直接给出的（“图中显示”“材料表明”）。
- [ ] 参考文献表里的条目，正文都引用过；正文引用的，表里都有。

**谬误排查**
- [ ] 稻草人：攻击的是对方真正的观点吗？
- [ ] 偷换概念：关键词前后意思一致吗？
- [ ] 虚假两难：除了这两个选项，真的没有第三个吗？
- [ ] 滑坡：每一步的因果链都有依据吗？
- [ ] 以偏概全：例子撑得起这个一般结论吗？
- [ ] 相关当因果：排除第三因素和反向因果了吗？
- [ ] 循环论证：结论有没有被偷偷当成了前提？
- [ ] 诉诸人身：反驳的是观点，不是人。
- [ ] “辩证”式回避：有没有用“要辩证看待”“各有利弊”代替了判断？

**讨论的四个阶段**（语用论辩学，van Eemeren 和 Grootendorst 提出的理想批判性讨论模型）
- [ ] 冲突阶段：分歧本身说清楚了（对应引言）。
- [ ] 开始阶段：讨论的共同出发点交代了，包括概念界定、双方都接受的事实（对应背景和概念部分）。
- [ ] 论辩阶段：论证和对论证的质疑都出现了（对应正文和反方）。
- [ ] 结束阶段：说清了论证的结果，主张在什么程度上被确立（对应结论）。

## 五、改稿诊断（“改论证”入口）

用户给了初稿时：

1. **拆**：把初稿的中心主张、每个分论点的主张、依据找出来，填成 `toulmin-unit.md` 第二节那样的蓝图。填不出来的格子就是问题。
2. **判**：用本文件第四节的清单逐条判断。
3. **列**：问题按影响大小排，先报给用户：

```markdown
| 位置 | 问题 | 改法 |
|---|---|---|
| 全文 | 没有中心主张，引言只说“本文将探讨……” | 根据第三节的内容，主张可以定为…… |
| 第二节第 3 段 | 只列了三组数据，没说数据怎么支持主张 | 补一句解释，并说明数据只覆盖城市样本 |
| 第四节 | 反方是稻草人：对方并没有主张“完全禁止” | 按……的原文重写复述 |
```

4. **改**：问题清单给出后直接动手改，不用等用户确认，除非改法会换掉中心立场或整体结构（这两种要先问）。改完附修改说明。

审稿时自己发现的东西（一个新推出的限定条件、一个巧妙的反驳），只能放进反方与回应那一处，作为限定或升华，不能升格成改稿的新主线。问题清单里也不要把它排成第一条修改方向。改完按第四节“主次”一组再检查一遍：原稿的主线还在不在，篇幅有没有被这个新点吃掉。

常见病和对应的改法：

| 初稿的样子 | 病根 | 改法 |
|---|---|---|
| 每段都是“首先……其次……最后……”罗列材料 | 有依据没保证 | 每段补上“这说明……，因为……” |
| 结论是“应当辩证看待” | 没有合题 | 回到第 2 步做分歧诊断，按正反合辩证式重写合题 |
| 反方只在倒数第二段出现一句 | 反方处理缺失 | 选最强的反方，按 Rapoport 规则写一段 |
| 主张说得很绝对，被一个反例就推翻 | 缺限定 | 找出反例所在的范围，写进主张 |
| 引言从“随着时代发展”写起 | 没有交代争议 | 改成从具体的分歧写起 |
| 某个限定或旁支在引言、正文、表格、结论里反复出现，读完记住的是它而不是主张 | 次要点膨胀 | 只在反方与回应处展开一次，其他地方删到一句或删掉；“先……才能……”改回“兼顾” |
